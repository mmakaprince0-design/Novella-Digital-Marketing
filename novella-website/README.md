## Run locally

Open `index.html` in a browser. No build step is needed.

## Edit your details

- **Business name and email:** search for `Novella` in `index.html` and `mmakaprince0@gmail.com` in `js/main.js`.
- **Colors and fonts:** change the variables at the top of `css/style.css` (the font is Poppins, loaded from Google Fonts).
- **Case study:** replace the sample content in the Cases section of `index.html`.

## Publish with GitHub Pages

1. Push this folder to a GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site will be live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
